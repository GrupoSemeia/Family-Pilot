# Family Pilot

Plataforma de ferramentas interativas para pais e mães encontrarem orientações práticas no dia a dia.
Um produto do Grupo Semeia Digital.

- `app/` — o app dos pais (PWA estático, sem build). Módulo pronto: **SOS Birra**. Veja `app/README.md`.
- `landing/sos-birra/` — landing page de vendas do SOS Birra (um único HTML com as imagens embutidas).

## Rodar o app
    python3 -m http.server 8080 --directory app   # http://localhost:8080
